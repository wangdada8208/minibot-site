如何体验离线演示？ / How do I try the offline demo?

打开连接页，点击“Try offline demo / 离线演示”（部分本地化文字可能显示为“体验本机模拟 / Try a local simulation”）。无需宿主地址或凭证。浏览示例 Bot，进入会话并输入测试文字，即可查看带有预设回复说明的本机回复。点击顶部“退出演示 / Exit demo”返回连接页并重置演示。

On the connection screen, choose “Try offline demo / 离线演示” (some localized builds may label this “Try a local simulation”). No host address or credentials are needed. Browse sample Bots, open a conversation and send test text to view a labeled preset reply. Tap “Exit demo” in the top banner to return to the connection screen and reset the demo.

演示不调用真实 AI、不执行工具、不连接真实宿主，示例不含私人数据；附件和语音等需要真实宿主的功能可能不可用。

The demo makes no real AI calls, runs no tools and connects to no real host. Samples contain no private data. Host-dependent features such as media and voice may be unavailable.

连接失败怎么办？ / What if connection fails?

向自己的宿主运营者获取有效连接地址和凭证，确认手机能访问宿主，并检查宿主是否在线、版本是否兼容、令牌是否过期，以及本地网络权限。连接前阅读并确认数据共享说明。优先使用可信 HTTPS 地址；HTTP 不加密传输。凭证失效时获取新连接信息，勿将完整连接链接发到公开反馈中。

Get valid connection details from your host operator. Check reachability, host uptime and compatibility, token expiry and local network permission. Review and confirm data sharing before connecting. Prefer trusted HTTPS; HTTP does not encrypt transport. Request fresh credentials when needed and never include a full connection link in public feedback.

断网或发送未确认怎么办？ / What about interrupted or unconfirmed sends?

恢复网络后先等待会话同步、查看回执及消息状态，避免反复点击导致重复操作。保留待确认提交和关联草稿，记录问题发生时间；不要为排查问题上传包含私人聊天或令牌的完整日志。

After reconnecting, wait for synchronization and check receipts and message status before retrying. Keep unresolved submissions and related drafts. Note when the issue happened and redact private chats and credentials from diagnostic material.

如何清理数据？ / How do I clear data?

断开连接会删除保存的凭证，但保留本机记录。设置中可清除当前宿主的缓存记录和草稿；未决发送及关联草稿、归档本机记录仍保留。操作不删除宿主或提供商的数据，重新打开会话可能下载历史。远端删除或撤销凭证请联系宿主运营者。更多说明见隐私政策。

Disconnecting removes saved credentials but keeps local records. Settings can clear cached history and drafts for the current host, retaining unresolved sends, related drafts and archived local records. This does not delete host or provider data; history may download again. Ask the host operator about remote deletion and credential revocation. See the privacy policy.

附件或语音不可用？ / Why are media or voice unavailable?

检查宿主能力及系统相册、相机、麦克风权限。选择附件后可立即上传至宿主；结束录音会发送至宿主转录，语音模式可自动提交停顿后识别的文字。离线演示不提供真实转录或模型服务。

Check host capabilities and device photo, camera and microphone permissions. Selecting attachments can upload them immediately. Finishing a recording sends it to the host for transcription, and voice mode may automatically submit recognized speech after a pause. The offline demo provides no real transcription or model service.
