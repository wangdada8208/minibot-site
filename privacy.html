Privacy policy

本政策说明 Minibot 客户端及本网站的数据使用。Minibot 连接用户自己配置的 MiniMax Bot 宿主；App 本身不提供模型服务。宿主运营者及第三方提供商的数据规则需要另行了解。

This policy covers the Minibot client and this website. Minibot connects to a MiniMax Bot host configured by the user; the app does not provide model services. The host operator and downstream providers have their own data practices.

你的设备 / Your device→你的宿主 / Your host→宿主配置的 AI 与工具 / Host-configured AI & tools

真实连接会传输数据。离线演示使用本机预设回复，不连接宿主或 AI 服务。

Connected use transmits data. The offline demo uses local preset replies without contacting a host or AI service.

1. 连接与第三方处理 / Connection and third-party processing

连接时，连接凭证发送至你配置的宿主进行认证。使用联网功能时，消息、附件、音频、转录请求及功能操作请求会发送至该宿主；宿主也会接收网络连接所需的信息，例如 IP 地址。宿主可能将内容转发给其配置的第三方 AI 提供商、转录服务及工具。具体提供商、用途、处理地点、保留期限和删除方式取决于宿主运营者及其配置，请在连接前向其确认。

连接前，App 要求确认向宿主及其配置的第三方 AI 和工具分享数据。只连接你信任的宿主，避免提交你无权分享的敏感信息。使用可信的 HTTPS 地址；HTTP 不提供传输加密。

Connection credentials are sent to your configured host for authentication. Connected features send messages, attachments, audio, transcription requests and feature-operation requests to that host. The host also receives connection information such as your IP address. It may forward content to configured third-party AI providers, transcription services and tools. Providers, purposes, processing locations, retention and deletion depend on the host operator and its configuration; ask the operator before connecting.

The app requires confirmation of sharing with your host and its configured third-party AI and tools before connection. Use only trusted hosts and do not share sensitive information without authorization. Use trusted HTTPS; HTTP does not encrypt transport.

2. 设备存储 / On-device storage

iOS 和 Android 的连接令牌使用系统安全存储。聊天记录、草稿、待确认提交、归档本机记录、宿主连接信息和偏好等使用本机缓存，按宿主区分；原生客户端使用 SQLite。缓存不等同于凭证的安全存储，不承诺与令牌相同的保护。浏览器开发预览的令牌仅在当前标签页内存中，缓存使用浏览器 localStorage。选择的文件、图片和录音也可能产生本机临时文件。

On iOS and Android, connection tokens use the system secure store. Local caches hold chat history, drafts, unresolved submissions, archived local records, host connection information and preferences, separated by host; native clients use SQLite. Cache storage is separate from secure token storage and is not promised the same protection. In the browser development preview, tokens stay in the current tab’s memory and caches use localStorage. Selected files, images and recordings may also create temporary local files.

3. 断开、保留与删除 / Disconnection, retention and deletion

断开连接会删除已保存的连接凭证和当前连接指向，但保留本机聊天记录、草稿及其他缓存；这不等于在宿主上注销或删除数据。设置中的“清除缓存记录和草稿”针对当前宿主：未决发送及其关联草稿、已归档的本机记录会保留，避免丢失尚未确认的操作。本机记录不会因退出而自动全部删除；没有统一的自动到期时限。

清除本机缓存不删除宿主或第三方提供商的数据；重新打开会话可能再次下载历史。需要删除远端数据、撤销设备凭证或了解远端保留期限时，请联系宿主运营者。设备端完整清理可使用操作系统的 App 数据管理；不同系统的安全存储保留行为可能不同，不能把卸载当作远端凭证撤销。

Disconnecting removes saved connection credentials and the active host reference, while retaining local history, drafts and other caches. It does not sign out or delete data on the host. “Clear cached history and drafts” in Settings applies to the current host; unresolved sends, their related drafts and archived local records remain to avoid losing unconfirmed operations. Local records are not all automatically deleted on exit and have no single automatic expiry period.

Clearing local caches does not delete host or provider records; reopening a conversation may download history again. Contact the host operator to delete remote data, revoke device credentials or learn remote retention periods. Use operating-system app data controls for device cleanup. Secure-store retention varies by platform; uninstalling is not remote credential revocation.

4. 权限与媒体 / Permissions and media

相机用于选择拍摄附件，以及可用的扫码入口；相册用于选择图片和头像；麦克风用于你主动开启的录音及语音功能。本地网络权限用于连接局域网宿主。可在设备系统设置中管理权限，拒绝后相应功能可能不可用。

在联网会话中，选定附件后即可上传至宿主，不必等点击发送消息。结束录音会将音频发送至宿主转录；语音模式在停顿后可自动提交识别文字并朗读回复。支持情况取决于宿主。请在使用这些功能前确认数据流和周围环境。

Camera access supports taking attachments and available scanning entry points; photo access supports selecting images and avatars. Microphone access supports recording and voice features you activate. Local network access supports connecting to a nearby host. Manage permissions in device settings; denying access may disable the corresponding feature.

In connected conversations, selecting an attachment can upload it to the host before you press Send. Finishing a recording sends audio to the host for transcription. Voice mode can automatically submit recognized speech after a pause and read replies aloud. Availability depends on your host. Check the data flow and your surroundings before using these features.

5. 离线演示 / Offline demo

演示示例不含私人数据，回复是本机预设文本，不是真实 AI 结果；不执行工具、不读取你的文件、不连接真实宿主或模型服务。你在演示中输入的文字仅用于本机演示会话，退出演示会重置该会话。演示不代表真实宿主能力或模型输出质量。

Demo samples contain no private data. Replies are local preset text, not AI results. The demo does not run tools, read your files or connect to a real host or model service. Text entered in the demo is used only for the local demo session, which resets when you exit. It does not demonstrate actual host capabilities or model quality.

6. 本网站 / This website

这些静态页面不含信息收集表单、第三方脚本、分析或广告代码，不设置网站追踪 Cookie。网站上线后，承载网站的服务可能处理访问所需的 IP 地址、浏览器请求及访问日志；具体保留规则需以最终托管服务为准，不能据此声称完全不处理数据。

These static pages contain no data collection forms, third-party scripts, analytics or advertising code and do not set tracking cookies. Once hosted, the hosting service may process IP addresses, browser requests and access logs to serve the site. Retention depends on the final hosting service; this is not a claim that no data is processed.
